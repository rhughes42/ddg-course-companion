# Examples

This folder contains practical usage notes plus lightweight Python helper material.

## C++ Executables
Built from `src/cpp/examples/`:
- `laplacian-smoothing`
- `curvature-analysis`
- `geodesic-distance`

## C# CLI Examples
Run from `src/csharp` via:
- `dotnet run -- smoothing`
- `dotnet run -- curvature`
- `dotnet run -- geodesic`
- `dotnet run -- conformal`
- `dotnet run -- vectorfield`

## Python Utility
- `examples/python/visualize_mesh.py` (experimental helper script)

## Notes
- Example outputs depend on mesh quality and topology validity.
- For reproducible checks, start with simple known meshes (single triangle, tetrahedron, grid).
